# Reference

Reference material for ContextForge. Start here for the deprecation
registry and the media kit.

## Deprecations

The [deprecations registry](../deprecations.md) lists every deprecated
interface. Each row carries the deprecation date, the earliest removal, the
migration path, and the current status.

The [deprecation policy](../development/deprecation-policy.md) defines the
lifecycle rules. It covers the 3 interface states, the removal windows, and
the approval path.

## Media kit

The [media kit](../media/kit/index.md) holds logos, icons, and press
material for ContextForge.
